## ⚡ Características Principales

- 🧹 **Limpiador y Normalizador de Texto:** Elimina saltos de línea dobles, espacios repetidos, viñetas, comillas curvadas y caracteres invisibles en un solo clic.
- 📊 **Analizador y Contador en Tiempo Real:** Métricas de palabras, caracteres puros, párrafos, tiempo de lectura y control de límites para redes y SEO.
- 🗂️ **Formateador & Validador JSON:** Analiza sintaxis, embellece con sangría configurable y minifica estructuras JSON sin enviar datos a servidores externos.
- 🔤 **Convertidor de Nomenclaturas:** Transforma cualquier texto a variables `camelCase`, `snake_case`, `kebab-case` y `CONSTANT_CASE`.
- 🔒 **100% Privado y Local:** Todo el cómputo se realiza dentro de la memoria de tu navegador (client-side). Tus datos nunca salen de tu equipo.
- 🌙 **Modo Oscuro / Claro:** Interfaz limpia, responsiva e intuitiva adaptada a tus preferencias del sistema.

## 💻 Instalación Local

Dado que la aplicación está construida con tecnologías estándar (*Vanilla JS*, *Tailwind CSS vía CDN* y *Lucide Icons*), no requiere la instalación de Node.js ni gestores de paquetes.

1. Clona este repositorio:
   ```bash
   git clone https://github.com/AldahirX/devutilidades.git
   ```
2. Abre el proyecto o sírvelo con cualquier servidor web estático.
